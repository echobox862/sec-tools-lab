# dict-generator · 弱口令字典生成器

> 需求分析：[docs/02-字典生成器-需求分析.md](../docs/02-字典生成器-需求分析.md)
> 基础词请使用自己拥有或已授权的信息；仓库不内置任何真实字典。

## 用法

```bash
python dicgen.py --base admin,test --years 2024-2026 --seps '',!,@ \
    --tails 123,1234 --templates '{base}{year},{base}{sep}{tail}' \
    --limit 1000000 -o pass.txt
```

| 参数 | 说明 |
|---|---|
| `--base` | 基础词（姓名拼音/公司名等自有信息），必填 |
| `--years` | 年份段 `2024-2026` 或列表（默认空） |
| `--seps` | 连接符（默认直连） |
| `--tails` | 数字尾巴（如 `123,1234`） |
| `--templates` | 组合模板，字段 `{base}{sep}{year}{tail}`，必填 |
| `--limit` | 最大产出条数（默认 100 万）；预估超限时拒绝，`--force` 放行 |
| `--append / --no-dedupe` | 追加模式 / 关闭去重 |

## 设计要点

- **生成器惰性输出**：字典可能上亿条，`yield` 边生成边写，内存恒定（实训核心教训：`list()` 会一次性物化全部）。
- **预估防爆闸门**：生成前按笛卡尔积算总量，超 limit 拒绝——对应 exrex `limit` 参数的防爆思想。
- **去重只存 8 字节指纹**，不存原文。
- 产出约定：一行一条、UTF-8 无 BOM，可直接作为 03/04 的 `--wordlist` 输入。
