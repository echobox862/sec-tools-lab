## 1. 核心业务对象与关键属性

### DictRule（生成规则）

| 属性 | 类型 | 说明 |
|---|---|---|
| `base_words` | list[str] | 基础词：姓名拼音、公司名、域名等（对应实训「弱密码规律：就地取材」） |
| `separators` | list[str] | 连接符：`''`、`'_'`、`'!'`、`'@'` 等 |
| `years` | list[str] | 年份段（规律：集中在近 2–3 年，如 2024–2026） |
| `number_tails` | list[str] | 数字尾巴：`'123'`、`'1234'`、`'000'` 等 |
| `templates` | list[str] | 组合模板，如 `'{base}{year}'`、`'{base}{sep}{num}'`、`'{base}{sep}{year}{sep}{num}'`——规则与数据分离（实训 `.format()` 模板思想的直接复用） |

### DictGenerator（生成器）

| 属性 | 类型 | 说明 |
|---|---|---|
| `rules` | list[DictRule] | 一或多条规则 |
| `limit` | int | 单条规则最大产出数（对应 exrex `limit` 的防爆思想） |
| `dedupe` | bool | 是否去重（默认 True；用 set 存已见指纹——**只存哈希不存原文**，控制内存） |

## 3. 实现步骤与模块依赖顺序

```
第1步 estimate_count   （纯计算：len(base)×len(sep)×len(year)×len(tail)×len(templates)）
第2步 generate         （依赖1的校验通过后才允许生成；yield 逐条产出）
第3步 write_stream     （依赖2：流式落盘，与2合并成管道）
第4步 dedupe 指纹去重  （插入在2的产出路径上）
第5步 CLI argparse     （串起全部；--limit 硬校验）
第6步(P1) exrex 后端   （独立可选）
```

依赖顺序上 **estimate_count 必须在 generate 之前**——这是防爆闸门，顺序不能反。

## 4. 边界条件与异常场景

| # | 场景 | 触发条件 | 预期行为 |
|---|---|---|---|
| 1 | 组合爆炸 | estimate 超过 limit（如默认 1,000,000） | **拒绝生成**，打印预估总量与超限提示；要求显式 `--force` 才放行 |
| 2 | 空输入 | base_words 为空列表 | ValueError「至少提供一个基础词」 |
| 3 | 空产出 | templates 全不匹配任何字段 | 产出 0 条 + 明确提示（不是静默成功） |
| 4 | 重复条目 | base=xx, year 出现两次同值 | dedupe 开启时写入数 < 生成数，报告「去重 N 条」 |
| 5 | 非法模板字段 | template 写了 `{passwrod}`（拼错） | 启动时校验模板占位符合法性，报错指出未知字段 |
| 6 | 输出文件已存在 | 目标路径已有文件 | 默认拒绝覆盖，`--append` 追加 / `--overwrite` 覆盖 |
| 7 | 磁盘写满 | 写入 IO 错误 | 保留已写入部分，报告实际完成条数 |
| 8 | 编码问题 | base 含非 ASCII（中文姓名拼音应转拼音） | 提示「检测到非 ASCII 字符」；不自动转拼音（P2） |
| 9 | 极大单条密码 | base 10MB 字符串 | 单条长度上限校验（如 64 字符），超限跳过并计数 |
| 10 | KeyboardInterrupt | 生成中 Ctrl+C | 已写入部分保留，打印完成条数 |

**合规边界（写进 README 与 --help）**：基础词应由使用者提供**自己拥有或已授权**的信息；工具不内置任何真实人员/公司数据。

## 5. MVP 划分

**必须实现（P0）**：模板规则引擎 + estimate_count 防爆 + 生成器流式输出 + 去重 + CLI。
**理由**：「弱密码=人类按习惯造的」这条规律（实训材料原话：姓名拼音+特殊字符+数字串/年份、公司名+数字）用模板引擎即可完整表达，不需要正则解析器。

**P1**：exrex 正则后端——实训原路径（`(admin|root|test){1,3}` 这类模式生成），作为对照实现保留。

**暂时不做（P2）**：正则解析器自研、姓名→拼音自动转换、社工信息组合（合规敏感且无授权数据源）、GUI。

## 6. 与其他工具的衔接

输出文件即 03/04 的 `--wordlist` 输入。约定**一行一条、UTF-8、无 BOM、换行 `\n`**，两个消费方按此解析，不引入额外配置。

## 7. 验收标准

- `--base admin --years 2024-2026 --tails 123` 能产出 admin2024 … admin2026123 全组合。
- estimate 超限时拒绝并展示预估数；`--force` 后正常生成。
- 生成 100 万条内存占用恒定（不随进度增长）——用任务管理器粗验即可。
- 产出文件可被 03/04 直接消费。
